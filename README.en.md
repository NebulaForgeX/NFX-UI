# NFX-UI

[中文](README.md)

Shared React library for NebulaForgeX (theme, i18n, hooks). **Not** a standalone site. Hosts: Identity, Vault, News, Storages, Documentation.

Exports and host wiring: [NFX-Documentation chapter 7](https://github.com/NebulaForgeX/NFX-Documentation/blob/main/books/en/chapter-07-nfx-ui.md). Current **0.31.0**; hosts pin exactly `"nfx-ui": "0.31.0"`. No `file:` dual path.

```bash
npm install
npm run build
```
